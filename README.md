Boothbnb is a development project that is built for vendors and host to discover, book and manages the booth event booth spaces.

The frontend uses Next.js and React for frontend. Next.js for taking advantage of server and client component but also better SEO. React for focusing on modern frontend framework and components based for better performance and also better code quality.
Tailwind CSS is also used for styling for frontend.

Other minor things that are also used include react-hook-form, zod, shad-cn, react-icons, react-hot-toast etc.

Thanks to leaftletjs and photon for map implementation in the app.

This frontend is hosted at vercel with Cloudflare protection : https://dev.boothbnb.online/
